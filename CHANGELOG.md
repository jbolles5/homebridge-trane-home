# Changelog

## 0.1.0 — 2026-10-20

First public release, following owner-reported stable operation on two Trane
XL1050 thermostats with Homebridge 2.4.0 and Node.js 24.20.0.

- Thermostat readings, modes, setpoints, humidity, hold, and fan selectors.
- Capability-gated optional equipment controls, RoomIQ, and vendor automations.
- Shared cloud session, bounded polling, stale-state handling, and read-only discovery.
- Explicit Permanent Hold, Fan Auto, Fan On, and Fan Circulate labels in Apple Home.
- Preserve accessory identities and user-customized names when upgrading from beta.
- Public installation, testing, attribution, and npm submission documentation.

No thermostat-control behavior changes from 0.1.0-beta.2.
